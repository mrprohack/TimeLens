# TimeLens V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Build a fast, privacy-first Manifest V3 Chrome extension that accurately tracks active website time, shows usage history, enforces daily limits, and supports focus sessions.

**Architecture:** Keep time/accounting logic in dependency-free pure ES modules and keep Chrome API access in one service worker adapter. Persist compact aggregates and recent sessions in `chrome.storage.local`; render a minimal popup plus a full dashboard and blocked page with shared design tokens.

**Tech Stack:** Chrome Manifest V3, vanilla ES modules, HTML/CSS, Chrome Tabs/Idle/Storage/Alarms APIs, Node.js built-in test runner.

## Global Constraints
- No external network requests, accounts, analytics, ads, or cloud sync.
- Permissions limited to `tabs`, `storage`, `idle`, and `alarms`.
- Count time only when active tab + focused window + active user are all true.
- Keep raw sessions 30 days and daily aggregates 365 days by default.
- UI must be keyboard accessible, responsive, and support light/dark preference.
